# v0.12 — Microduck/XGO lossless Lean ↔ URDF case conversion

Implementation commit: `a4f1ff271a627519f3cd80ff781c081833859d52`.

The old Lean proof records lacked the frames, geometry, material and inertial data
needed to generate a complete URDF. This release adds a complete data-only Lean
document that the installed Lean renderer actually executes. It also preserves
asset bytes and, when starting from a native bundle, the original controller,
free-base, BOM/source and proof records in bound native resources.

Use `fk robot to-lean INPUT --output LEAN_PACKAGE` and
`fk robot from-lean LEAN_PACKAGE --output RESTORED`. The
[workflow and exact boundaries](../LOSSLESS_ROBOTS.md) explain the representation,
editing policy and distinction between semantic and lexical losslessness.

## Case acceptance

All four cases passed. These inputs are the existing pinned v0.9 native models and
the selected v0.10 personalized models; the validation used zero model calls and
did not change their designs.

| Case | Bodies | Articulated joints + free base | Actuators | Exact sealed files restored |
| --- | ---: | ---: | ---: | ---: |
| Microduck | 15 | 14 + 1 | 14 | 226 |
| XGO Duck | 15 | 14 + 1 | 14 | 208 |
| Microduck personalized | 16 | 14 + 1 | 14 | 251 |
| XGO Duck personalized | 16 | 14 + 1 | 14 | 229 |

For each case, acceptance required all of the following:

1. Native bundle → Lean package → native bundle preserves every sealed file and
   manifest byte, including URDF, meshes, controller records and source evidence.
2. Converting that restored bundle to Lean again produces byte-identical
   `Robot.lean` source. Original input hashes remain unchanged.
3. A separate URDF-only Lean package, with its original XML deliberately removed
   and no native sidecar, reconstructs the complete XML information tree by actual
   Lean execution. All attribute values, numeric lexemes and text match.
4. Native structural proofs are reexecuted. Restored native projections pass the
   independent MuJoCo/FK checks. Each standalone Lean-generated URDF passes a fresh
   native import, both actual Lean certificates and numerical consumer checks.

The [benchmark](2026-09-29-v0.12-evidence/benchmark.json) records source hashes and
every acceptance result. Complete Lean documents are archived for
[Microduck](2026-09-29-v0.12-evidence/microduck/Robot.lean),
[XGO](2026-09-29-v0.12-evidence/xgoduck/Robot.lean), and their personalized variants.
These are evidence extracts; full packages and assets remain locally under
`.demo/v012-lossless-final/`. Source license notices accompany the evidence.

The initial native restoration test exposed a portability issue: sealed packages
correctly omit the machine-local `.lake` cache, but proof reexecution assumed that
cache existed. Verification now rebuilds the checked proof project first; the
clean-cache test and all final cases pass. Earlier failed local runs remain under
`.demo/v012-lossless/`; the final benchmark uses a fresh directory.

The installed CAD Viewer lacks its documented `agent:start` entry point. Startup
failed, so this release does not claim a new interactive visual inspection.
[Viewer status](2026-09-29-v0.12-evidence/viewer.json) records that limitation.

## What “lossless” means here

The full URDF information is present in the Lean tree, rather than in a copied
partial proof record. Exact XML formatting/comments/declaration additionally use
a digest-bound lexical snapshot, accepted only after its tree agrees with Lean.
Meshes remain external, hash-bound files. Ordinary URDF does not encode native
controller/BOM/evidence fields: a bound native sidecar is required to preserve
those fields as well.

This is demonstrated lossless conversion for these complete case packages. It
does not accept arbitrary Lean programs, infer missing metadata, prove a general
XML round-trip theorem, or establish robot physical correctness. The Python
parser/binding checks remain trusted; Lean executes the complete serializer and
the separately scoped existing certificates. Imported mechanisms and personalized
hardware remain physically unverified.

Implementation details and evidence remain in the private repository.
