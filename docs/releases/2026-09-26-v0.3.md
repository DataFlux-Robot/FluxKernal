# FluxKernel v0.3 — constrained local revisions

An agent can inspect a parent run, submit a versioned numeric patch, preview its
effects, and execute it without rewriting the whole design. The parent manifest
is pinned by SHA-256. Requirements, routes, material choices, catalog identities
and numeric constraints survive the edit. The repository remains private.

## Demonstrable behavior

The enclosure task changes a housing wall from 2 mm to 3 mm, rebuilds that housing,
and reuses the exact STEP/STL bytes of 23 product/equipment entities. Manufacturing
receipts, the plan and Lean evidence are regenerated. A 5 mm wall is rejected
before CAD because it violates the wall bound and payload clearance.

Two additional tasks exercise nominal shaft/sleeve clearance and mounting-datum
spacing. Each includes an accepted and a rejected patch. These are authored
regression fixtures with zero model calls, not image-reconstruction evaluations.

## Interfaces and integrity

- Python: `inspect_run`, `preview_revision`, `generate_task`, `apply_revision`.
- CLI: `fk schema revision`, `fk inspect`, `fk task`, `fk revise`, `fk benchmark`.
- Patches can change only size, position, rotation and wall, within the finite
  recipe schema. Purchased parts cannot be resized through this API.
- Parent artifacts are hash-checked and snapshotted before reuse. Stale parents,
  modified artifacts, escaping paths and protected-field edits are rejected.
- The original model-driven revision path also inherits numeric constraints.
- The exported verifier reevaluates the constraints and binds both the contract
  and checker source to the frozen input. Editing the checker and rebuilding only
  the file manifest does not bypass this binding.
- Studio labels fixtures and local revisions explicitly as not calling a model.

See [Agent API](../AGENT_API.md) for runnable examples, diagnostics and limits.

## Scope

The numeric interface checks run in Python; they are not new Lean theorems. Lean
checks the finite manufacturing plan under its declared assumptions. Neither
check establishes physical fit, material strength, machining accuracy or sourced
catalog qualification. A manifest is an integrity commitment, not a signature.

The new API is local and bounded; this release does not introduce autonomous
general product design or arbitrary-depth equipment synthesis. The next gate is
sourced assembly interfaces and measured fit. No PyPI upload, public-visibility
change or public-showcase update was performed.
