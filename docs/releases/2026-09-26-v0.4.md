# FluxKernel v0.4 — local MCP integration

An external agent can now discover and execute the existing bounded engineering
workflow through MCP: create an authored task, inspect its parent identity, preview
a parameter edit, apply it, and inspect the resulting evidence. The server uses the
official MCP Python SDK over stdio. It makes no model calls. The repository remains
private.

## Delivered

- Eight tools with explicit input schemas and read/write annotations. Revision
  tools embed the canonical v1 patch schema instead of duplicating it.
- Two resources for capabilities/limits and the revision request schema.
- An explicit workspace boundary: run IDs rather than caller-supplied paths,
  symlink-run rejection, an allowlist of JSON reports and verified artifact listings.
- Read-only mode both hides and disables writes. One writer per server process;
  a concurrent generation receives a busy diagnostic.
- Structured MCP error results for malformed requests, engineering rejection,
  stale parents, missing runs, modified artifacts and worker failures.
- `fk-mcp`, `fk doctor --profile agent`, English/Chinese onboarding and the
  [MCP guide](../MCP.md).
- A packaged real-client reproduction command:
  `python -m fluxkernel.agent_smoke --workspace ./agent-runs --require-proof`.

## Limits

This adapter exposes the existing finite tasks and local patch vocabulary; it does
not add image inference, general assembly synthesis or physical manufacturing
validation. SDK interoperability is tested, not every third-party host UI. Core
and MCP protocol checks on macOS/Windows do not imply native CAD/Lean support there.

Writes create fresh runs and are not idempotent. Client cancellation does not roll
back a worker; inspect history before retrying. The write lock is process-local.
The workspace assumes local filesystem ownership and is not a hostile-process
sandbox. Numerical constraints remain Python checks; Lean separately checks the
conditional manufacturing plan.

No public repository visibility, PyPI package publication, public showcase change
or model credential change was performed. The next engineering milestone remains
sourced assembly interfaces and measured physical fit.
