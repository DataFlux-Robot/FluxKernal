# v0.5 — Studio perception–action loop

Live image generation now renders real CAD into four fixed views, sends those views
and the reference image to GLM, applies bounded edits, and evaluates candidates again.
Saved runs can start the same loop with `fk perceive`. A run with unresolved visual
problems remains `needs-review` even when Lean accepts its manufacturing plan.

The action validator protects procurement dimensions, part identities, routes,
requirements and numeric constraints; invalid edits receive one repair attempt.
All rejected attempts, renders, reviews and candidate choices remain in the bundle.
Independent bundle verification binds the selected candidate to final exported CAD.
New smooth body/segment recipes expand the available geometry without changing old
recipes. This remains a finite concept geometry vocabulary.

## Interpretation

Model ratings are subjective; the reference camera is not aligned, hidden structures
are hypotheses, and physical capability is unverified. The next useful improvements
are surface/feature editing, attachment and symmetry constraints, and camera-aware
visual evaluation. More iterations alone cannot supply geometry operations that do
not exist. See [PAL behavior and limits](../PERCEPTION_ACTION_LOOP.md).
