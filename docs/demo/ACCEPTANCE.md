## 保留的开发失败与边界

早期存在非流式 API 超时、适配器合同枚举错误、壳体方向错误和模型生成的尺寸约束错误。失败目录保留。后续改为有时限的流式响应、校正合同、增加几何方向检查；飞机案例第一轮候选被检查拒绝，模型根据错误修正后通过。成功表格不是所有尝试均一次成功的声明。

目前是工程概念和制造路线演示。几何为有限参数化基本体与放样；目录件为采购候选和包络，加工件为毛坯。制造路线结构闭合不意味着几何复刻、装配无干涉、工艺合格或整机功能实现。材料特定打印能力、无限成型包络、原料、电源和基础装配均为外部假设。

实用化下一步应优先完善供应商目录和接口证据、装配碰撞与配合检查、局部厚度与支撑、真实刀路/设备能力验证，再做实体打印与装配试验。当前未证明递归生产带来经济收益，也未进行模型权重训练。
